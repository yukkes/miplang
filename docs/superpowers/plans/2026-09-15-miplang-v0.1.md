# MIPLang v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the first working MIPLang vertical slice: parse an LP/MILP model into deterministic canonical JSON IR and verify that TypeScript, Python, Java, Go, and Rust runtimes can load the same IR.

**Architecture:** A dependency-light Go compiler owns language parsing and semantic validation. The emitted versioned JSON IR is the sole contract consumed by five thin runtimes; solver integration is deliberately deferred so the language/runtime boundary can stabilize first.

**Tech Stack:** Go 1.23+, standard-library parser/compiler, JSON Schema, Python 3.11+, Node 22+, Java 21+, Rust stable, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-15-miplang-v0.1-design.md`

## Global Constraints

- LP/MILP only; reject nonlinear variable-by-variable multiplication.
- No AMPL implementation code or reverse engineering.
- Canonical IR must be deterministic and versioned as `miplang.ir/v1alpha1`.
- Model syntax exists only in `.mip`; runtimes do not implement parser logic.
- Runtime packages remain thin and solver-neutral in v0.1.
